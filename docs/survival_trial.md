# 基础生存搭档试玩入口

适用于MC1.21.1／NeoForge21.1.217的独立服务器、本机Agent和单个ServerBody。玩家只开自己的MC客户端；服务器安装控制Mod，Agent与MCP在本机运行。验收状态以[交付计划](delivery_plan.md)为准，本页是启动与体验步骤，不代替验收记录。

2026-10-05[首版受限基础搭档验收](archive/server_alpha_release_validation.md)已完成：R8容器、六种矿石普通产物、Codex生存工具及真实聊天叫停通过，另有普通世界选定路线短跟随。自然段不是长期野外生存，本轮未新增30分钟测试；Claude保留既有证据，新增矿石未在本轮使用Claude实测。隔离验证服已保存关闭，配置按备份实际字节恢复；记录已于2026-10-06提交。

## 准备

1. 构建`client-runtime`与`mods/mcbot-server-control`，先备份获授权的测试存档，再将生成的`mcbot-server-control-0.1.0.jar`装入隔离服务器。不要同时安装早期spike模块。
2. 启动服务器，确认自己的玩家能进入；连接配置使用该服务器生成的`config/mcbot-server-control/connection.json`，不分享文件中的控制凭据。
3. Agent账号只在运行Agent的机器上登录。本轮Codex沿用本机已登录环境；如果选择Claude，先确认当次使用的账号，不沿用10月3日Claude-b选择作为新的授权，不自动回退或搬运登录配置。
4. 本机Node24.15曾出现尚未定位的原生退出。可通过`-NodePath`选择已验证的现有Node24.19，不修改全局安装。

先检查配置：

```pwsh
./start-server-play.ps1 -Agent codex -Nickname '小克' -Effort low -ConnectionFile '<测试服>/config/mcbot-server-control/connection.json' -NodePath '<Node24.19的node.exe>' -PrepareOnly
```

检查通过后去掉`-PrepareOnly`启动托管；不指定`-ConfigDir`或`-Model`时沿用本机现有Codex登录与默认模型。示例显式指定昵称“小克”，以下聊天使用该昵称；省略时Codex昵称默认为“Codex”。Claude也沿用同一启动器，但须明确选择当次账号后设置`-Agent claude -ConfigDir '<本机已确认的Claude配置目录>'`。启动器默认Agent仍为Claude，没有修改默认设置。首版准备和启动围绕这个入口，不需要另开Bot游戏客户端。

### 单人世界

也可以不开服务器，直接用单人世界（2026-10-06 起，见[单人模式](singleplayer_design.md)）：

1. 把 `mcbot-server-control` 放进客户端实例的 `mods`。
2. 进单人世界，按 Esc 选「对局域网开放」，作弊开不开都行，点「创建局域网世界」。不开局域网时 Bot 会拒绝接管：没开局域网的单人世界一按 Esc 就会暂停，Bot 的动作会失败。
3. 连接文件用实例里的 `config/mcbot-server-control/connection.json`，其余同上。每个存档的记忆按存档名分开（`sp-<存档文件夹名>`）。
4. 退出到标题后托管会结束；重新进世界、开局域网后再运行一次启动脚本。

## 五分钟体验

使用有食物、普通原版斧／剑／镐的测试角色。当前可以从主背包准备到热栏，但不会从空背包自动合成整套装备。

- “小克，告诉我你的血量、饥饿和当前自动进食、防卫策略。”
- “跟着我。”带它走过平地障碍、半砖、楼梯和一格台阶；不要用梯子、游泳或跨沟跳跃验收本轮。
- “用合适的工具拿两块原木。”明确指定测试树／方块；有限资源目录不能判断方块属于天然地形还是玩家建筑。
- 在已授权的近处铁矿试“拿两份粗铁”；普通煤／铁／铜矿及深层变种分别采煤／粗铁／粗铜，拒绝精准矿石块目标，不包含合成或熔炼。数量以实际拾取为准，铜多产物或时运可能超额。
- 食物放在主背包而非热栏，观察饥饿时程序进食。普通进食尽量等任务间隙，紧急进食会取消当前工作。
- 在受控环境靠近一只普通敌对怪物，观察自动防卫与任务中断；再说“关闭自动防卫”。玩家、友军和未激怒的中立生物默认排除。
- 动作进行中说“小克，停下”，等角色自然停稳后再发一个全新小任务。停止不应踢出角色或恢复旧工作；空中已有重力和惯性不会被伪造消除。

## 当前限制

防卫是有限近身行为，不追杀；低血或点燃苦力怕先尝试有界安全退让，没有安全路线时会停止报告，不能保证救险。未知Mod武器、未核验的附魔／行为组件不擅自使用；普通原版工具资格与速度估计不等于所有Mod钩子都已适配。

采集目录包含5种石料、8种原木及煤／铁／铜和深层共6种矿石；已有石料／原木代表样本及六种矿石普通产物的实服证据，不把目录数量当作逐项实测覆盖。范围和候选冻结，不补扫扩区。R8整栈取物、90秒总期限与额度诊断也已验收，4096操作额度耗尽行为仍仅有离线覆盖。普通世界只验证了选定路线短跟随，测试玩家被定位到目标点、Bot原生步行，不代表任意地形、自动开门、游泳／梯子或长期野外生存。持续陪挖还待真实模型和用户验收；合成熔炼、完整建筑、不开局域网的单人模式、异机传输和多版本尚未交付。原建筑skill的设计资料仍可迁移，新ServerBody建筑执行器尚未接通。
