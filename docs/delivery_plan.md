## 目标

1. **Agent 接入（主线）**：同一个 ServerBody 和同一组 MCP 工具，可以选用 Claude Code、Codex、DeepSeek Harness（dsh）或原生 API。dsh 的需求最高，优先做。
2. **Mod 适配：接口加示例**：核心模组开放适配接口，我们自己做 2～3 个示例；其他 Mod 由使用者按接口自己适配。适配器做成装上就能用的附属模组。
3. **多版本、多加载器**：按需求再做，不提前铺开。

## 还没解决的

- **持续陪挖**：代码已提交，实服矩阵在暂停/恢复场景出现 `COMPANION_OUT_OF_RANGE`（挖 1 块、新拾取 0），根因待查，不算交付。真实 Codex 陪挖脚本还没跑。
- **Node 24.15**：在 Windows 上有一次没定位的原生退出（0xC0000409），目前用 Node 24.19 加 `-NodePath` 绕开。
- **评审遗留**（见 [评审修复记录](archive/boundary_review_fixes.md)）：R5 Mod 适配器分派入口、R6 容器和地面物品的观察降级、R7 Agent 会话入口和公共工具执行入口的拆分。
- **建筑**：设计资产还在，ServerBody 没有建筑执行入口。先拿 3×3 小亭验证，见 [生存 Alpha 计划](archive/survival_alpha_plan.md) 第 5 节。
- **单人模式（内置服务器）**：没验收（暂停时控制怎么处理等）。观众大多玩单人，排在下一步第 2 步。
- **许可证**：仓库还没有统一许可证，别人要自己写适配前得先定，建议 Apache-2.0。

## 规则

- 2026-10-06 起可以开测试服、编译和构建（10-05 的暂停已解除）。用户电脑上还有别的项目在编译：开服或构建前先看 CPU 和内存占用，别的编译在跑就等它结束；构建完不留常驻 daemon。真实模型测试仍按下一条先问账号。
- 每轮真实 Claude 测试前，先问用户这次用哪个账号，不擅自切换。
- 中文交流，Windows 用 `pwsh`；没必要不计算或校验哈希/指纹，比较文件直接比字节或字段。
- 离线检查、实际模型、真实游戏三类证据分开报告；不把受限场景说成任意 Mod 或服务器都能用。
