# 试玩步骤

适用于 MC 1.21.1 / NeoForge 21.1.217 的独立服务器（或开了局域网的单人世界）、本机 Agent、单个 Bot。玩家只开自己的客户端，Bot 是服务器里的假玩家。能做什么、验证到什么程度以[交付计划](delivery_plan.md)为准，本页只讲怎么开始玩。2026-10-08 更新；10-05 首版验收时的旧步骤见 git 历史和[首版验收](archive/server_alpha_release_validation.md)。

## 准备

1. 构建 `client-runtime`（`npm ci`、`npm run build`）和 `mods/mcbot-server-control`（`./gradlew.bat build`），把核心 jar 装进服务器的 `mods`。想用示例适配就再装对应的附属模组和被适配的 Mod（见 `mods/mcbot-*/README.md`）。改服务器前先备份存档。
2. 启动服务器，确认自己能进。服务器会生成 `config/mcbot-server-control/connection.json`，里面有控制令牌，只留在本机，不要发给别人。
3. Agent 账号在本机登录好（Claude Code、Codex 或 DeepSeek Harness）。用哪个账号由自己选，程序不会自动切换或复制登录。
4. 单人世界：把核心 jar 放进客户端实例的 `mods`，进世界后按 Esc 选「对局域网开放」再托管（不开局域网会拒绝接管，见[单人模式](singleplayer_design.md)）；连接文件用实例里的那份。

## 用 WebUI 启动

```pwsh
node scripts/webui.mjs --open
```

在「配置」页新建一份配置：

- Agent、账号目录、模型、思考强度：试玩一般用 low。
- 连接文件：填服务器的 `connection.json`，点「检查」能看到角色名和世界。
- 记忆目录：放人设和玩家档案的目录（有 `xiaoke/persona.md` 时旁边会显示找到人设）。留空就没有人设，说话会比较像客服。
- 保护玩家：默认开，可以调范围、撤退血量、用不用弓和盾。
- 外观：服务器装了 YSM 和 YSM 适配时出现，从服务器上的模型里选，每次启动托管时套用。

点「保存并启动托管」。「监控」页能看到游戏聊天、AI 的回复和工具调用；「叫停」让 Bot 停下当前的事、等新指令，「停止托管」让 Bot 下线。角色上次死了的话，启动托管时会先重生。

命令行版本（WebUI 也是调用它）：

```pwsh
./start-server-play.ps1 -ConnectionFile '<服务器>/config/mcbot-server-control/connection.json' -Agent claude -ConfigDir '<账号目录>' -MemoryDir '<记忆目录>' -Effort low
```

加 `-PrepareOnly` 只检查配置、不启动。

## 可以试的

在游戏聊天里用 Bot 的名字或昵称叫它：

- “跟着我”“等一下”“继续跟”。跟着的时候它会保护你：靠近你的怪会去打，血少了往你这边撤。
- “砍这棵树”“砍三棵树”“挖几个铁矿”。它会自己找、走过去、垫高、捡掉落，做完在聊天里说结果。
- “帮我做一把铁镐”“把这些铁烧了”“附魔一下这把剑”。附魔、铁砧这类先预览，问过你再做。
- “帮我收一下麦子”“把这两头牛喂一下”“在这开块地”。
- “记住这里是家”“回家”。晚上在家附近会提醒你睡觉；你上床它也会去找床。
- “穿上这件胸甲”“盾牌拿到副手”。
- 打招呼、让它点头、跳个舞（装了 YSM 时能播模型动画）。
- 做事中途说“小克，停下”，再给一个新任务。

## 当前限制

- 还不会建筑，不会用模组机器（只认登记了适配的），长途行走只做了 `travel-to` 分段走。
- 托管途中死了，控制会结束，要重新启动托管。
- 很多能力只在平坦隔离服实测过，自然地形、复杂地形、真实模型下的表现以试玩为准；具体每项的证据见交付计划。
- 程序遇到结果不确定（unknown）时不会自动重试，会如实报告，由你决定接下来怎么做。
