## 目标

1. **Agent 接入（主线）**：同一个 ServerBody 和同一组 MCP 工具，可以选用 Claude Code、Codex、DeepSeek Harness（dsh）或原生 API。dsh 的需求最高，优先做。
2. **Mod 适配：接口加示例**：核心模组开放适配接口，我们自己做 2～3 个示例；其他 Mod 由使用者按接口自己适配。适配器做成装上就能用的附属模组。
3. **多版本、多加载器**：按需求再做，不提前铺开。
